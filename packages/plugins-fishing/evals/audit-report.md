## 简化声明（What is simplified）

- 剖面是 2D 垂直切面：线组画在 x=0 一列，不走水时不画横向位移；走水的斜拉由漂相 / 姿态文案表达。
- 钓组布局是"状态 → 位置"的纯函数，不积分动力学：没有线的质量、没有波的扰动。
- 咬钩 / 中鱼概率是分区查表 × 倍率（装备 / 情况 / 水温 / 漂相权重），不是逐鱼个体行为。
- 提竿窗口按漂相取常数（1.1 ~ 1.9s），不是真实提竿时机分布。
